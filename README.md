# Світло

Вводиш адресу — бачиш графік відключень для свого будинку.

| Область | Як працює |
|---|---|
| Київ, Дніпропетровська | адреса → черга → графік через API Yasno |
| Київська, Одеська, Донецька | адреса → черга → графік із сайту DTEK (через невидимий браузер — сайти DTEK закриті від ботів), запасний варіант — дзеркало [outage-data-ua](https://github.com/Baskerville42/outage-data-ua) |
| Інші 19 областей | офіційна сторінка обленерго відкривається всередині застосунку |

Без мережі показується останній збережений графік. Для будинків DTEK
окремо показується поточне аварійне чи планове відключення.

## Збірка

GitHub Actions збирає `Svitlo.ipa` для iPhone на кожен пуш у `main` —
файл зʼявляється в Releases.

IPA не підписана: на iPhone її ставлять через Sideloadly або AltStore
з власним Apple ID (безкоштовний акаунт — на 7 днів, потім переставити).

Локально:

```
flutter pub get
flutter run
```
