Сервери Черкасиобленерго і Запоріжжяобленерго віддають неповний ланцюжок
сертифікатів — у `assets/certs` лежать офіційні проміжні сертифікати
Sectigo і Certum, перевірка TLS не вимикається.

Перевірка всіх областей на живих даних: `flutter test test_live/live_regions_test.dart`.

Без мережі показується останній збережений графік. Для будинків DTEK
окремо показується поточне аварійне чи планове відключення.

## Збірка

GitHub Actions збирає `Svitlo.ipa` для iPhone на кожен пуш у `main` —
файл зʼявляється в Releases.

IPA не підписана: на iPhone її ставлять через Sideloadly або AltStore
з власним Apple ID (безкоштовний акаунт — на 7 днів, потім переставити).

Локально:

```
flutter pub get
flutter run
```
